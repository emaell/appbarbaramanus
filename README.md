# Cuidar com Dra. Bárbara

Um aplicativo mobile premium e gratuito para acompanhar o desenvolvimento e saúde de bebês e crianças pequenas.

## 🎯 Sobre o Aplicativo

**Cuidar com Dra. Bárbara** é um PWA (Progressive Web App) desenvolvido para mães, pais e responsáveis do Brasil. O aplicativo oferece ferramentas práticas e educativas para acompanhar o crescimento, desenvolvimento e bem-estar de bebês e crianças pequenas.

### Características Principais

- **Dashboard Personalizado**: Saudação com hora do dia, card da criança ativa, próximas vacinas
- **Acompanhamento de Crescimento**: Gráficos de peso, altura e perímetro cefálico
- **Diário Completo**: Registro de aleitamento, fraldas, sono, sintomas e saúde digestiva
- **Biblioteca Educativa**: 10 materiais gratuitos, vídeos e 16 FAQs
- **Calendário de Vacinas**: Acompanhamento completo das imunizações
- **Modo Noturno**: Interface adaptável para uso confortável
- **Dados Locais**: Todos os dados são armazenados no seu dispositivo
- **PWA Completo**: Funciona offline com Service Worker

## 🚀 Como Usar

### Instalação

1. Acesse o aplicativo no navegador
2. Clique em "Adicionar à tela inicial" (iOS) ou "Instalar" (Android)
3. O aplicativo será instalado como um app nativo

### Primeiros Passos

1. **Cadastre sua Criança**
   - Vá para a aba "Perfil"
   - Clique em "Adicionar Criança"
   - Preencha os dados: nome, data de nascimento, sexo, tipo de alimentação

2. **Explore o Dashboard**
   - Aba "Hoje": Visão geral da criança e atalhos rápidos
   - Aba "Crescimento": Registre medidas e veja gráficos
   - Aba "Diário": Registre atividades diárias
   - Aba "Conteúdos": Acesse materiais educativos
   - Aba "Perfil": Gerencie configurações e vacinas

### Funcionalidades por Aba

#### Hoje (Dashboard)
- Saudação personalizada
- Card da criança com idade exata
- Próxima vacina agendada
- Últimas atividades registradas
- Atalhos rápidos para registros
- Vídeo e material em destaque

#### Crescimento
- Registre peso, comprimento/altura e perímetro cefálico
- Visualize gráficos de evolução
- Acompanhe o desenvolvimento
- Exporte resumo para consultas médicas

#### Diário
- **Aleitamento**: Cronômetro, registro de mamadas, leite ordenhado
- **Fraldas**: Registre xixi, cocô e observações
- **Sono**: Acompanhe padrões de sono
- **Sintomas**: Registre febre, tosse, vômito, etc.
- **Saúde Digestiva**: Formulário para preparar consulta
- **Observações**: Notas livres sobre a criança

#### Conteúdos
- 10 materiais gratuitos em PDF
- 2 vídeos educativos
- 16 FAQs com busca
- Filtros por categoria e idade

#### Perfil
- Cadastro de múltiplas crianças
- Calendário de vacinas (15 vacinas)
- Configurações de aparência (modo claro/escuro)
- Informações de privacidade (LGPD)
- Contato direto com Instituto Naves via WhatsApp

## 📱 Compatibilidade

- ✅ iOS 12+
- ✅ Android 5+
- ✅ Navegadores modernos (Chrome, Safari, Firefox, Edge)
- ✅ Funciona offline com Service Worker

## 🔒 Privacidade e Segurança

- **Dados Locais**: Todos os dados são armazenados localmente no seu dispositivo
- **Sem Compartilhamento**: Seus dados nunca são enviados para servidores
- **LGPD Compliant**: Respeita a Lei Geral de Proteção de Dados
- **Sem Diagnóstico Automático**: O app é educativo, não substitui pediatra

## ⚠️ Avisos Importantes

- Este aplicativo é **educativo** e não substitui a orientação de um profissional de saúde
- Sempre consulte seu pediatra para diagnósticos e prescrições
- Sinais de alarme são alertas educativos, não diagnósticos
- Em caso de emergência, procure atendimento médico imediatamente

## 📞 Suporte

Tem dúvidas? Entre em contato conosco pelo WhatsApp do Instituto Naves através do botão na aba Perfil.

## 🛠️ Tecnologia

- **Frontend**: React 19 + TypeScript + Tailwind CSS
- **Gráficos**: Recharts
- **Armazenamento**: IndexedDB + localStorage
- **PWA**: Service Worker + Manifest.json
- **Testes**: Vitest
